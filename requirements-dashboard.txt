# Minimal dependency set for deploying the T3 dashboard/live-pipeline
# (t3_engine/) on its own - e.g. on Render.
#
# WHY THIS FILE EXISTS: the full requirements.txt at the repo root also
# contains the legacy app.py's dependencies (pandas/numpy/matplotlib/scipy/
# Pillow/python-binance/flask), pinned to old versions from before this
# work. Those packages have no prebuilt wheel for newer Python releases
# (e.g. 3.14) and fail trying to compile from source (a Cython/numpy
# version mismatch - "Build aborted: the NumPy Cython headers require
# Cython 3.0.0 or newer"). None of that is needed to run the T3 dashboard -
# it does not import pandas/numpy/matplotlib/scipy anywhere - so the
# correct fix is to not install them for this deployment at all, rather
# than chase compatible pins for packages this service never uses.
#
# render.yaml points its buildCommand at this file. If you want both the
# legacy app.py AND the T3 dashboard installed in one environment, use the
# root requirements.txt and make sure PYTHON_VERSION is pinned to 3.11.x
# (see runtime.txt / render.yaml) so pandas/numpy resolve to prebuilt wheels.
