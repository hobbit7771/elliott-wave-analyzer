Timeout

Seconds to wait for one answer. Free router models queue behind other traffic and reasoning models think before emitting a first token, so a slow reply is normal — a read timeout means the connection worked and the model was still busy, which is a different problem from a wrong URL.

AI wave labelling

The model proposes a count across the whole loaded history — the one thing the deterministic engine deliberately won't do, since it only anchors on recent pivots. The model only ever names pivot indices; the server recomputes those pivots itself and re-checks existence, order, contiguity, alternation, causality and the hard Elliott rules before anything is drawn. A mathematically impossible wave comes back rejected, with the rule it broke.
A clean chart and an agent, nothing else. This tab loads the candles and hands the model no markup — no pivots, no BOS/CHoCH, no scenarios, no Fibonacci — then lets it work the chart with real tools: list the swings at any degree, measure legs, compute Fibonacci levels, and test a count against this server's rule engine before committing to it. It is told the Elliott rulebook (hard rules vs. guidelines, impulses, diagonals, zigzags, flats, triangles, combinations) and asked to work top-down, oldest structure first.
